# Changelog

All notable changes are documented here. RepoMend follows Semantic Versioning.

## [1.0.0] - 2026-07-17

### Added

- Deterministic Git, privacy, file, dependency, workflow, documentation, community, and optional GitHub checks.
- Pretty, JSON, and Markdown reports with stable finding identifiers.
- Dry-run-first safe fixes for `.gitignore` and repository-local noreply Git identity.
- Opt-in public GitHub metadata, Pages, and current-commit Actions checks.
- Cross-platform Node.js CLI with no runtime dependencies.
- Automated tests, CI matrix, release packaging, security policy, configuration guide, and roadmap.
